Entry for the [make.fun](https://make.fun) competition
[The Excuse That Almost Works](https://make.fun/c/u-clever-harbor-75-the-excuse-that-almost-works-69fde8f5):
the single line a gamer texts the boss to skip work on GTA 6 launch week,
in one line of at most 20 words and 140 characters.

## The line

> My laptop updated overnight and now it only boots to a screen asking for a password I never set

(95 characters, 19 words.)

## Run

```sh
node main.ts   # writes the line to /output/entry.txt
```

`main.ts` runs on Node 22.18+ (TypeScript run natively) and writes the single
line to `/output/entry.txt`, deterministically — every run produces the exact
same bytes.
